## Repositorio de referencia

Con el propósito de realizar las pruebas de rendimiento sobre un sistema con características similares al caso planteado, se empleó como referencia el repositorio **NovaChef Restaurant Platform**:

- https://github.com/OwerLopez/novachef-restaurant-platform

La elección de este proyecto se fundamenta en que incorpora procesos de negocio comparables a los del escenario analizado, incluyendo la administración de inventario, la gestión de pedidos y la coordinación de entregas (delivery). Estas funcionalidades permitieron ejecutar pruebas de carga representativas y obtener métricas de desempeño relacionadas con operaciones críticas del sistema.
